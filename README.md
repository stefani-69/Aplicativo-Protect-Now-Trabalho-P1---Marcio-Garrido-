# Aplicativo-Protect-Now-Trabalho-P1---Marcio-Garrido-
O Protect Now é uma aplicação desktop desenvolvida para solucionar problemas críticos de vazamento de dados confidenciais entre filiais corporativas fictícias (Maricá e Niterói).  Equipe do projeto: Bruno Pepe, Eduarda Lima, Stefani Gonçalves e Yasmin dos Santos.
